CTF challenges are now available through the InfiShark CLI.

- Create and verify an account, sign in, and track progress shared with the CTF website.
- Prepare a challenge target with verified firmware downloads, load its encrypted flag, read hints, and submit a solution.
- Restore stock firmware after a challenge, with cancellation checks around firmware preparation.
- Use the expanded Bluetooth GATT, Wi-Fi, infrared and HID commands included in this release.

CTF preparation requires matching protocol-2 challenge firmware. Keep the attacker Nano on stock firmware. Dedicated paired-device challenges will become available separately.

Use the standard InfiShark installer to update, then run `infishark ctf --help`. This release includes Linux x86-64/ARM64, macOS Intel/Apple Silicon and Windows x86-64 packages, along with archive checksums and source provenance.
